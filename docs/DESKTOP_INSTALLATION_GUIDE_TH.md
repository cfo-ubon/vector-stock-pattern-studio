# คู่มือติดตั้ง Vector Stock Pattern Studio (เวอร์ชัน Desktop)

เวอร์ชันนี้เป็นโปรแกรม Windows ที่ทำงานแบบออฟไลน์ทั้งหมด — หลังติดตั้งเสร็จแล้ว
ไม่ต้องต่ออินเทอร์เน็ตเพื่อใช้งานฟีเจอร์หลักใดๆ (สร้างลาย, export SVG/EPS/PNG,
บันทึกโปรเจกต์)

## ความต้องการของเครื่อง

- Windows 11 64-bit (แนะนำ) — ควรรองรับ Windows 10 64-bit รุ่นใหม่ด้วย แต่ยัง
  ไม่ได้ทดสอบจริง
- ไม่ต้องมีสิทธิ์ผู้ดูแลระบบ (Administrator) สำหรับการใช้งานปกติ

## วิธีติดตั้ง (ตัวติดตั้ง .exe)

1. ดับเบิลคลิกไฟล์ `VectorStockPatternStudio-Setup-x64.exe`
2. หากมีหน้าต่างเตือนจาก Windows SmartScreen ("Windows protected your PC")
   ให้กด **More info** แล้วกด **Run anyway** — เกิดขึ้นเพราะไฟล์ยังไม่ได้ลงลายเซ็น
   ดิจิทัลแบบเสียเงิน ไม่ใช่สัญญาณว่าไฟล์เป็นอันตราย
3. เลือกโฟลเดอร์ที่จะติดตั้ง (หรือใช้ค่าเริ่มต้น) แล้วกด **Install**
4. ติดตั้งเสร็จแล้วโปรแกรมจะเปิดขึ้นอัตโนมัติ หรือหาไอคอนได้จาก:
   - เมนู Start → พิมพ์ "Vector Stock Pattern Studio"
   - ไอคอนบนหน้าจอ Desktop (ถ้าเลือกตอนติดตั้ง)

การติดตั้งเป็นแบบ **ต่อผู้ใช้ (per-user)** — ไม่ต้องใช้สิทธิ์ Administrator และ
จะไม่ติดตั้งลงในโฟลเดอร์ที่ผู้ใช้อื่นในเครื่องเดียวกันเข้าถึงได้

## วิธีเปิดโปรแกรม

- จากเมนู Start: ค้นหา "Vector Stock Pattern Studio" แล้วกด Enter
- จากไอคอน Desktop: ดับเบิลคลิก
- โปรแกรมจะเปิดเป็นหน้าต่างแอปพลิเคชันปกติ ไม่มีหน้าต่าง terminal/command
  line ใดๆ ปรากฏขึ้น

## วิธีสร้างโปรเจกต์แรก

1. เปิดโปรแกรม แล้วเลือก File → New Project (หรือ Ctrl+N)
2. เลือก Style Family / Category ที่ต้องการ แล้วกด "สร้างลายใหม่"
3. เมื่อพอใจกับผลลัพธ์ กด File → Save (Ctrl+S) — โปรแกรมจะถามให้เลือกตำแหน่ง
   บันทึกไฟล์ `.vsps` (เช่น `Documents\ลายดอกไม้ฤดูใบไม้ผลิ.vsps`)

## วิธีบันทึกและ Export

- **Save / Save As**: File → Save หรือ File → Save As — บันทึกเป็นไฟล์
  โปรเจกต์ `.vsps` ไฟล์เดียว เก็บครบทั้งลาย, palette, Style DNA, metadata
- **Export SVG/EPS/PNG**: ปุ่ม Export ในแต่ละลาย จะเปิดหน้าต่างเลือกตำแหน่ง
  บันทึกไฟล์ของ Windows โดยตรง (native Save dialog) — ไม่ใช่การดาวน์โหลดผ่าน
  เบราว์เซอร์เหมือนเวอร์ชันเว็บ

## ไฟล์ถูกเก็บไว้ที่ไหน

| ข้อมูล | ตำแหน่ง |
|---|---|
| ไฟล์โปรเจกต์ `.vsps` | ที่ที่คุณเลือกเองตอน Save (ค่าเริ่มต้นมักเป็น `Documents`) |
| ไฟล์ที่ Export (SVG/EPS/PNG/ZIP) | ที่ที่คุณเลือกเองตอน Export |
| การตั้งค่าแอป, รายการโปรเจกต์ล่าสุด, log | `%APPDATA%\Vector Stock Pattern Studio\` |
| ข้อมูลลายที่บันทึกไว้ในคลัง (Saved Library), Portfolio | ฐานข้อมูลภายในของแอป ในโฟลเดอร์เดียวกับข้างบน |
| ไฟล์สำรอง (Backup) | `Documents\Vector Stock Pattern Studio\Backups\` |

## วิธีสำรองข้อมูล (Backup)

ดูรายละเอียดเต็มที่ `docs/BACKUP_AND_RECOVERY.md` — สรุปสั้นๆ: เมนู Tools →
Backup Data เพื่อสำรองด้วยตนเอง หรือปล่อยให้โปรแกรมสำรองอัตโนมัติทุก 30 นาที
(ปรับได้ในหน้า Settings) ไฟล์สำรองเก็บที่
`Documents\Vector Stock Pattern Studio\Backups\` เสมอ ไม่ได้อยู่ในโฟลเดอร์
ติดตั้งโปรแกรม จึงไม่หายแม้ถอนการติดตั้งแอป

## วิธีกู้คืนข้อมูล (Restore)

เมนู Tools → Restore Data → เลือกไฟล์สำรองจากรายการ → โปรแกรมจะเปิดไฟล์นั้น
เหมือนเปิดโปรเจกต์ปกติ (ถ้ามีงานที่ยังไม่ได้บันทึกอยู่ โปรแกรมจะถามก่อนเสมอ)

## วิธีใช้เวอร์ชัน Portable (ไม่ต้องติดตั้ง)

1. ดาวน์โหลด `VectorStockPatternStudio-Portable-x64.exe`
2. วางไฟล์ไว้ในโฟลเดอร์ใดก็ได้ที่คุณเขียนไฟล์ได้ (รวมถึง USB drive)
3. ดับเบิลคลิกเพื่อเปิดใช้งานได้ทันที ไม่ต้องติดตั้ง
4. เวอร์ชัน Portable เก็บข้อมูลแยกจากเวอร์ชันที่ติดตั้ง (ไม่ใช้
   `%APPDATA%` ร่วมกัน) และไม่เขียนไฟล์ลงโฟลเดอร์ Program Files — เหมาะสำหรับ
   พกพาไปใช้เครื่องอื่นโดยข้อมูลไม่ปนกัน

## วิธีถอนการติดตั้ง (Uninstall)

1. Windows Settings → Apps → ค้นหา "Vector Stock Pattern Studio" → Uninstall
   (หรือ Control Panel → Programs and Features)
2. การถอนการติดตั้งจะ**ไม่ลบ**ไฟล์โปรเจกต์ `.vsps` ของคุณ, ไฟล์ที่ Export
   ไว้, หรือไฟล์สำรองใน `Documents\Vector Stock Pattern Studio\Backups\`
   — ไฟล์เหล่านี้อยู่นอกโฟลเดอร์ติดตั้งโปรแกรมเสมอ
3. หากต้องการลบข้อมูลการตั้งค่า/ฐานข้อมูลภายในด้วย ต้องลบโฟลเดอร์
   `%APPDATA%\Vector Stock Pattern Studio\` เองด้วยตนเอง (ตัวติดตั้งจะไม่ลบ
   ให้อัตโนมัติ เพื่อป้องกันการลบข้อมูลโดยไม่ตั้งใจ)
