# แก้ปัญหาเบื้องต้น — Vector Stock Pattern Studio (Desktop)

## โปรแกรมไม่เปิดขึ้นเลย

1. ตรวจสอบว่าเครื่องเป็น Windows 11 (หรือ Windows 10) แบบ 64-bit — เวอร์ชัน
   32-bit ไม่รองรับ
2. ลองเปิดใหม่อีกครั้งโดยดับเบิลคลิกที่ไอคอนโดยตรง (ไม่ใช่ shortcut ที่อาจชี้
   ผิดตำแหน่งหลังย้ายไฟล์)
3. ถ้าเพิ่งอัปเดตเวอร์ชัน ลองถอนการติดตั้งแล้วติดตั้งใหม่ (ข้อมูลโปรเจกต์และ
   การตั้งค่าจะไม่หาย — ดู `docs/DESKTOP_INSTALLATION_GUIDE_TH.md`)
4. เปิดโฟลเดอร์ log ด้วยตนเอง (ไม่ต้องเปิดโปรแกรม) ที่
   `%APPDATA%\Vector Stock Pattern Studio\logs\` แล้วดูไฟล์ log ล่าสุด
   (`vsp-YYYY-MM-DD.log`) เพื่อดูข้อความ error

## Windows แจ้งเตือน "Windows protected your PC" ตอนติดตั้ง

เป็นเรื่องปกติสำหรับโปรแกรมที่ยังไม่ได้ซื้อใบรับรองลายเซ็นดิจิทัลราคาแพง —
ไม่ได้แปลว่าไฟล์เป็นไวรัส กด **More info** แล้วกด **Run anyway** เพื่อดำเนินการ
ติดตั้งต่อ

## บันทึกโปรเจกต์ไม่ได้ / ขึ้นข้อความ "บันทึกไฟล์ไม่สำเร็จ"

1. ตรวจสอบว่าโฟลเดอร์ปลายทางไม่ได้ถูกล็อกไว้ (เช่น อยู่ใน OneDrive ที่กำลัง
   sync ค้าง หรือไฟล์เดิมถูกเปิดค้างในโปรแกรมอื่น)
2. ตรวจสอบพื้นที่ว่างในดิสก์
3. ลองบันทึกไปที่โฟลเดอร์อื่น (เช่น `Documents`) เพื่อแยกว่าปัญหาอยู่ที่
   โฟลเดอร์เดิมหรือไม่
4. ชื่อไฟล์/ชื่อโปรเจกต์ที่มีอักขระต้องห้ามของ Windows (เช่น `< > : " / \ | ?
   *`) จะถูกแทนที่ด้วย `_` ให้อัตโนมัติอยู่แล้ว — ไม่ควรทำให้บันทึกไม่ได้ แต่ถ้า
   เจอปัญหานี้ ให้ลองเปลี่ยนชื่อโปรเจกต์เป็นภาษาอังกฤษ/ตัวเลขล้วนเพื่อทดสอบ

## เปิดไฟล์ `.vsps` ไม่ได้ / ขึ้นว่าไฟล์เสียหาย

- ตรวจสอบว่าไฟล์มีนามสกุล `.vsps` จริง (ไม่ใช่ไฟล์ที่โดนเปลี่ยนนามสกุลมา)
- ถ้าไฟล์ถูกส่งผ่านอีเมล/แชท บางระบบอาจบีบอัด/แปลงไฟล์ระหว่างทาง — ลองส่งใหม่
  แบบใส่ใน ZIP ก่อนส่ง
- ลองเปิดไฟล์สำรองล่าสุดแทน (Tools → Restore Data) ถ้าไฟล์หลักเสียหายจริง

## Export SVG/EPS/PNG แล้วหาไฟล์ไม่เจอ

- ตรวจสอบการตั้งค่า "เปิดโฟลเดอร์ export อัตโนมัติหลัง export เสร็จ" ใน
  Preferences — ถ้าเปิดไว้ โฟลเดอร์ที่บันทึกจะเปิดขึ้นเองทันทีหลัง export
- ถ้าปิดอยู่ ให้ดูที่ "โฟลเดอร์ Export เริ่มต้น" ในหน้า Settings หรือใช้เมนู
  Tools → Open Export Folder เพื่อเปิดโฟลเดอร์ที่ export ไฟล์ล่าสุดไว้

## ชื่อโปรเจกต์/ชื่อไฟล์ภาษาไทยมีปัญหา

รูปแบบไฟล์ `.vsps` และระบบไฟล์ทั้งหมดรองรับ Unicode เต็มรูปแบบ (ทดสอบจริงแล้ว
ว่าชื่อโปรเจกต์ภาษาไทยเก็บและอ่านกลับมาได้ถูกต้อง 100% — ดู
`docs/PROJECT_FILE_FORMAT.md`) หากพบปัญหาจริงกับชื่อไฟล์/โฟลเดอร์ภาษาไทยบน
เครื่อง Windows โดยเฉพาะ กรุณาแจ้งปัญหาพร้อมแนบ Diagnostic Package (ดูด้านล่าง)

## วิธีเก็บข้อมูลไปแจ้งปัญหา (Diagnostic Package)

Help → Export Diagnostic Package จะสร้างไฟล์ JSON ที่มี:
- เวอร์ชันแอป, เวอร์ชัน Windows, สถาปัตยกรรมเครื่อง (64-bit)
- log ล่าสุด 3 วัน
- สรุปการตั้งค่า (ไม่รวมเนื้อหาไฟล์ลายจริงของคุณ)

ไฟล์นี้**ไม่มี**ลายเวกเตอร์หรือเนื้อหาโปรเจกต์ของคุณอยู่ในนั้น ปลอดภัยที่จะส่ง
ให้ทีมสนับสนุนตรวจสอบปัญหา

## ยกเลิกการเปลี่ยนแปลงที่ยังไม่ได้บันทึก

ถ้าปิดโปรแกรมโดยมีงานที่ยังไม่ได้บันทึกอยู่ โปรแกรมจะถามให้เลือกก่อนเสมอ:
"บันทึกแล้วปิด" / "ปิดโดยไม่บันทึก" / "ยกเลิก" — เลือก "ยกเลิก" เพื่อกลับไป
ทำงานต่อโดยไม่ปิดโปรแกรม

## ยังแก้ปัญหาไม่ได้

ตรวจสอบ `docs/DESKTOP_INSTALLATION_GUIDE_TH.md` และ
`docs/DESKTOP_USER_GUIDE_TH.md` เพิ่มเติม หรือแนบ Diagnostic Package
(ด้านบน) พร้อมคำอธิบายปัญหาให้ทีมพัฒนา
