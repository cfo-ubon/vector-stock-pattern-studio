# คู่มือใช้งาน Vector Stock Pattern Studio (เวอร์ชัน Desktop)

คู่มือนี้อธิบายเฉพาะส่วนที่เพิ่มเข้ามาสำหรับเวอร์ชัน Desktop — ฟีเจอร์การสร้างลาย,
scoring, SEO, portfolio ฯลฯ เหมือนกับเวอร์ชันเว็บทุกประการ ดู
`docs/USER_GUIDE.md` สำหรับคู่มือฟีเจอร์หลักฉบับเต็ม

## เมนูของโปรแกรม

### File
- **New Project** (Ctrl+N) — เริ่มโปรเจกต์ใหม่
- **Open Project...** (Ctrl+O) — เปิดไฟล์ `.vsps`
- **Save** (Ctrl+S) — บันทึกทับไฟล์เดิม (ถ้ายังไม่เคยบันทึก จะถามตำแหน่งเหมือน Save As)
- **Save As...** (Ctrl+Shift+S) — บันทึกเป็นไฟล์ใหม่
- **Import JSON...** — นำเข้าไฟล์ Project JSON ที่เคย export ไว้ (จากเวอร์ชันเว็บ
  หรือจาก desktop เอง)
- **Export** — เปิดหน้าต่างเลือกรูปแบบ export (SVG/EPS/PNG/ZIP)
- **Recent Projects** — รายการโปรเจกต์ที่เปิดล่าสุด (สูงสุด 20 รายการ)
- **Exit** — ปิดโปรแกรม (จะถามก่อนถ้ามีงานที่ยังไม่ได้บันทึก)

### Edit
- **Undo / Redo** — ยกเลิก/ทำซ้ำการแก้ไขล่าสุด
- **Reset Current Pattern** — รีเซ็ตลายปัจจุบันกลับค่าเริ่มต้น
- **Preferences...** — เปิดหน้า Settings

### View
- **Zoom In / Zoom Out / Reset Zoom** — ปรับขนาดการแสดงผลของหน้าต่าง
- **Full Screen** — สลับโหมดเต็มจอ
- **Toggle Developer Tools** — แสดงเฉพาะในเวอร์ชัน dev เท่านั้น (ไม่มีในเวอร์ชัน
  ที่ติดตั้งจริงจาก installer/portable)

### Tools
- **Validate Current Pattern** — ตรวจสอบคุณภาพลายปัจจุบัน
- **Duplicate Check** — ตรวจลายซ้ำในคลัง
- **Generate Preview** — สร้าง PNG preview ใหม่
- **Rebuild Metadata** — สร้าง SEO metadata ใหม่
- **Open Export Folder** — เปิดโฟลเดอร์ที่ export ไฟล์ล่าสุดไว้
- **Backup Data** — สำรองข้อมูลโปรเจกต์ปัจจุบันด้วยตนเอง
- **Restore Data** — กู้คืนจากไฟล์สำรอง

### Help
- **User Guide** — เปิดคู่มือฉบับเต็ม
- **Keyboard Shortcuts** — แสดงรายการคีย์ลัดทั้งหมด
- **Open Logs Folder** — เปิดโฟลเดอร์เก็บ log สำหรับแนบตอนแจ้งปัญหา
- **About Vector Stock Pattern Studio** — เวอร์ชันโปรแกรมและข้อมูลผู้พัฒนา

## หน้า Settings

Edit → Preferences เปิดหน้าตั้งค่า ซึ่งจดจำค่าไว้ข้ามการเปิด-ปิดโปรแกรมเสมอ:

- โฟลเดอร์ Export เริ่มต้น
- โฟลเดอร์โปรเจกต์เริ่มต้น
- ขนาดไฟล์ PNG ที่ export (พิกเซล)
- ขนาด preview
- ค่าตั้งต้นของการ export SVG/EPS/ZIP
- ความถี่การบันทึกอัตโนมัติ (autosave)
- ความถี่การสำรองข้อมูล (backup)
- ภาษา (ไทย/อังกฤษ)
- ธีม (สว่าง/มืด/ตามระบบ)
- Stock site เริ่มต้น (Shutterstock, Adobe Stock ฯลฯ)
- รูปแบบชื่อไฟล์ export
- เปิดโฟลเดอร์ export อัตโนมัติหลัง export เสร็จ (เปิด/ปิด)
- จดจำค่าที่ใช้ล่าสุด (เปิด/ปิด)

## ไฟล์ของแต่ละลาย (Pattern) เกี่ยวข้องกันอย่างไร

เมื่อ export ลายหนึ่งลาย จะได้ไฟล์ที่ตั้งชื่อขึ้นต้นเหมือนกัน แต่คนละนามสกุล:

- `<ชื่อไฟล์>.svg` — ไฟล์เวกเตอร์หลัก แก้ไขต่อได้ใน Affinity Designer 2 /
  Adobe Illustrator
- `<ชื่อไฟล์>.eps` — เวอร์ชัน EPS สำหรับ stock site ที่ต้องการไฟล์ประเภทนี้
- `<ชื่อไฟล์>.png` — พรีวิวความละเอียดสูง
- `<ชื่อไฟล์>.json` — ข้อมูลพารามิเตอร์ของลาย (seed, palette, category ฯลฯ) —
  ใช้สร้างลายเดิมซ้ำได้แน่นอน (deterministic)

ไฟล์โปรเจกต์ `.vsps` เก็บทุกอย่างข้างต้นรวมกันไว้ในไฟล์เดียว (ดูรายละเอียดที่
`docs/PROJECT_FILE_FORMAT.md`)

## ความแตกต่างจากเวอร์ชันเว็บ

- **Export**: เวอร์ชันเว็บดาวน์โหลดผ่านเบราว์เซอร์ (โฟลเดอร์ Downloads
  เสมอ) เวอร์ชัน desktop เปิดหน้าต่างเลือกตำแหน่งบันทึกของ Windows โดยตรง —
  เลือกโฟลเดอร์ไหนก็ได้
- **บันทึกโปรเจกต์**: เวอร์ชันเว็บเก็บในเบราว์เซอร์เท่านั้น (IndexedDB) —
  ถ้าล้างข้อมูลเบราว์เซอร์จะหายได้ เวอร์ชัน desktop บันทึกเป็นไฟล์ `.vsps`
  จริงบนเครื่อง ย้าย/แชร์/สำรองได้อิสระ
- **การทำงานแบบออฟไลน์**: ทั้งสองเวอร์ชันไม่เรียก API ภายนอกสำหรับฟีเจอร์
  หลักอยู่แล้ว — เวอร์ชัน desktop เพิ่มระบบสำรองข้อมูล/กู้คืนข้อมูลระดับไฟล์ที่
  เวอร์ชันเว็บไม่มี (เพราะเว็บไม่มี "ไฟล์บนเครื่อง" ให้สำรอง)
