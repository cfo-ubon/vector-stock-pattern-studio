# 📖 คู่มือการใช้งาน Vector Stock Pattern Studio

> **ลิงก์เข้าใช้งาน:** https://cfo-ubon.github.io/vector-stock-pattern-studio/studio/
>
> คู่มือนี้จะถูกอัปเดตทุกครั้งที่แอปมีการเปลี่ยนแปลง — ดู[บันทึกการอัปเดต](#-บันทึกการอัปเดต)ท้ายเอกสาร

แอปสร้างลวดลายเวคเตอร์แบบ **seamless (ต่อกันไร้รอยต่อ)** สำหรับขายบนเว็บ stock
เช่น Shutterstock, Adobe Stock, Freepik, Creative Fabrica — ทุกอย่างทำงานใน
เบราว์เซอร์ ไม่เรียก AI API ไม่มีค่าใช้จ่ายต่อครั้ง สร้างได้ไม่จำกัด

---

## 🚀 เริ่มใช้งานใน 1 นาที

1. เปิดแอปที่ลิงก์ด้านบน
2. กดปุ่ม **Generate 9 variations** — ระบบจะสุ่มลาย 9 แบบเข้า Gallery ให้เลือก
3. คลิก thumbnail ที่ชอบใน Gallery — ลายจะขึ้นที่ Preview ใหญ่
4. ตรวจว่า repeat เนียน (ดูตรงรอยต่อระหว่าง tile ใน preview 3×3)
5. กด **Export single tile (.svg)** เพื่อดาวน์โหลดไฟล์
6. เปิดแผง **SEO สำหรับ Stock** ใต้ preview → กดคัดลอก Title / Description /
   Keywords ไปวางในฟอร์มอัปโหลดของ Shutterstock ได้ทันที

### 🧩 Asset Mix — ผสมหลายหมวดในลายเดียว 🆕

ติ๊กช่อง **🧩 Asset Mix** เหนือรายการหมวด แล้วเลือกได้ **2-5 หมวด** (คลิก
chip เพื่อเลือก/ยกเลิก) — เมื่อกด Generate ระบบจะสุ่มหยิบ "หมวดต้นทาง"
ของ **ชิ้นลายแต่ละชิ้นแยกกัน** จากหมวดที่เลือกไว้ ไม่ใช่สุ่มทั้งลายจากหมวด
เดียว ผลลัพธ์คือลายแบบ **eclectic asset-mix** ที่มีทั้งใบไม้ เรขาคณิต
ลายเสือดาว ฯลฯ ปนกันอย่างเป็นธรรมชาติในไฟล์เดียว — เหมือนดึงชิ้นงานจาก
"คลัง asset" หลายชุดมาประกอบเป็นลายใหม่

- เลือกได้สูงสุด 5 หมวดต่อครั้ง ต้องมีอย่างน้อย 2 หมวดเสมอ (ยกเลิกช่องสุดท้าย
  ไม่ได้ถ้าจะเหลือหมวดเดียว — ให้ปิด Asset Mix แทน)
- ชื่อไฟล์ export และ SEO metadata จะระบุหมวดที่ผสมไว้ให้อัตโนมัติ
  (เช่น `... mix geometric x botanical x plaid-check ...`)
- ปุ่ม **Randomize All** มีโอกาส ~25% ที่จะสุ่มเปิด Asset Mix ให้เองด้วย
- AI ช่วยคิดลาย (ด้านล่าง) ก็สั่ง Asset Mix ได้เช่นกัน โดยให้ AI ตอบ field
  `"categories"` เป็น array แทน `"category"` เดี่ยว

### Layout — ระบบการจัดองค์ประกอบ (14 แบบ)

**5 แบบพื้นฐาน**

- **Grid** — ตารางแถว-คอลัมน์ตรงๆ (คลาสสิกสุด ดูเป็นระเบียบ)
- **Brick / Offset** — สลับแถวครึ่งช่องแบบก่ออิฐ
- **Radial / Mandala** — จัดกลุ่มวนรอบจุดศูนย์กลางเป็นเหรียญ
- **Random Scatter** — โปรยแบบสุ่มแต่คุมระยะห่าง (ลาย ditsy)
- **Half-Drop** — สลับคอลัมน์ครึ่งช่อง (มาตรฐานวงการ textile/wallpaper)

**9 Composition ยอดนิยมตลาด Stock 🆕** — จำลองระบบจัดองค์ประกอบที่นักออกแบบ
ลายจริงใช้ขาย ไม่ใช่แค่สุ่มตำแหน่ง มี "ลำดับความสำคัญ" ของชิ้นลายด้วย

| Composition | ลักษณะ |
|---|---|
| **Hero + Editorial Flow** | ชิ้นใหญ่ (hero) 3-5 ชิ้นเรียงตามเส้นโค้งทแยงมุม + ชิ้นกลางประกบข้าง + ชิ้นเล็กแทรกพื้นที่ว่าง |
| **Hero + Scatter** | ชิ้นใหญ่ไม่กี่ชิ้นวางห่างๆ + ชิ้นเล็กจำนวนมากโปรยรอบๆ |
| **S-Curve Botanical** | ชิ้นลายเรียงตามเส้นโค้ง S ซ้ำกัน 2-3 เส้น (ทิศทางลายหมุนตามเส้นโค้ง) |
| **Bouquet** | จับกลุ่มชิ้นลาย 5-8 ชิ้นเป็น "ช่อ" กระจุกแน่น แล้ววางช่อซ้ำทั่วลาย |
| **Airy Botanical** | โปร่งมาก มีพื้นที่ว่างเยอะ ชิ้นลายเล็กเป็นหลัก แซมชิ้นใหญ่บ้างเล็กน้อย |
| **Toss Pattern** | โปรยแบบสุ่มหมุนอิสระ 360° ชิดกันมากกว่า scatter ทั่วไป (สไตล์ "โยนลาย") |
| **Dense Premium** | ซ้อน 3 ชั้นขนาด (ใหญ่/กลาง/เล็ก) ที่ความหนาแน่นสูง ลายแน่นหรูไม่มีจุดโล่ง |
| **Grid Minimal** | ตารางโปร่งมีไม่กี่ชิ้น ขนาดเท่ากันหมด ไม่หมุนไม่สุ่มขนาด — มินิมอลจริงๆ |
| **Stripe** | จัดชิ้นลายเป็นแถบแนวนอนมีช่องว่างระหว่างแถบ ไม่ใช่เต็มพื้นที่แบบ grid |

> 🆕 ทั้ง 9 composition มาจากผลสำรวจระบบจัดองค์ประกอบลายเวคเตอร์ที่ขายดี
> ที่สุดบน Adobe Stock/Shutterstock/Freepik/Creative Market ปี 2026

### Palette — ชุดสี (18 ชุด)

คลิกแถบสีเพื่อเลือก เช่น Pastel Dream, Earth Tone, Sage & Terracotta,
Retro Sunset, Midnight Botanical ฯลฯ — สีแรกของทุกชุดคือ **สีพื้นหลัง**

- **Colors (2–6)** — จำนวนสีที่ใช้จริงจากชุด (น้อย = ลาย minimal, มาก = คึกคัก)

### Diversity Controls — ตัวปรับความหลากหลาย

- **Density** — ความหนาแน่นของ motif (สูง = แน่น, ต่ำ = โปร่ง) ปรับได้ทีละ
  **5%** ผ่านปุ่ม **−5% / +5%** ข้างแถบเลื่อน หรือลากแถบเลื่อนเอง (สแนปทีละ 5%
  เหมือนกัน) — บางหมวด (เช่น Plaid & Check, Terrazzo) จะปรับ density ให้
  อัตโนมัติเป็นค่าที่เหมาะสมทันทีที่เลือกหมวดนั้น เพราะเป็นลายที่ต้องวาง
  ชิดกันแทบไม่มีช่องว่างถึงจะดูถูกต้อง (เช่น checkerboard/gingham)
- **Motif size** — ขนาดชิ้นลาย
- **Rotation randomness** — สุ่มหมุนแต่ละชิ้น (0° = เป๊ะทุกชิ้น)
- **Scale jitter** — สุ่มขนาดแต่ละชิ้น (ทำให้ดู hand-made ขึ้น)
- **Mirror symmetry** — พลิกชิ้นสลับกัน
- **Radial symmetry fold** — จำนวนแฉกสมมาตร (มีผลกับ layout Radial)

### Seed

รหัสสุ่ม — **ลายเดียวกัน 100% จะกลับมาเมื่อใช้ seed + ค่าปรับเดิมทุกตัว**
จดหรือ copy seed เก็บไว้ถ้าอยากกลับมาแก้ลายเดิมภายหลัง (กด 🎲 เพื่อสุ่มใหม่)

## 🤖 AI ช่วยคิดลาย (ไม่ต้องใช้ API key)

แผงล่างสุดของคอลัมน์ควบคุมซ้ายมือ — ให้ AI ภายนอก (ChatGPT / Claude / Gemini)
ช่วยคิดคอนเซ็ปต์แล้วส่งค่ากลับมาให้แอป gen จริง โดยไม่มีค่าใช้จ่าย API:

1. กด **"1. คัดลอก Prompt ไปถาม AI"** — prompt อธิบาย schema ของแอปครบถ้วน
   (จะพิมพ์ brief เพิ่มท้าย prompt ก็ได้ เช่น "ลายฤดูใบไม้ร่วงสำหรับห่อของขวัญ")
2. วาง prompt ในแชท AI ที่ใช้อยู่ แล้วคัดลอกคำตอบ (เป็น JSON) กลับมา
3. วางในช่องแล้วกด **"3. สร้างลายจาก JSON"** — ทุกไอเดีย (สูงสุด 9) จะถูก
   gen เข้า Gallery ทันที เลือกดู/แก้ต่อ/export ได้เหมือนลายปกติ

AI สามารถกำหนดได้ทุกอย่าง: หมวด, layout, palette สำเร็จรูป **หรือส่งชุดสี
custom เป็น hex เอง** (สีแรก = พื้นหลัง), ความหนาแน่น, ขนาด, การหมุน, seed ฯลฯ
ถ้า JSON ผิดรูปแบบ แอปจะบอกว่าแก้ตรงไหน ค่าที่เกินช่วงจะถูกปรับให้อัตโนมัติ

## 🖼 Preview และ Gallery

- **Preview กลางจอ** ค่าเริ่มต้นแสดงเป็น **1×1 (ภาพเดี่ยว)** ตรงกับที่ขายจริง
  (ไฟล์เดียวไม่ต่อกัน) — สลับดู 2×2 / 3×3 / 4×4 ได้ที่มุมขวาบนเพื่อเช็คว่า
  ต่อกันเนียนก่อน export จริง
- **🔍 ขนาดลวดลาย (ปรับหลัง gen ได้) 🆕** — แถบเลื่อนเหนือ preview ปรับได้
  40–250% ทีละ 5%: ย่อลง = ลายละเอียดชิ้นเล็กซ้ำถี่ขึ้น, ขยาย = ชิ้นใหญ่โดดเด่น
  ขึ้น โดย**ความหนาแน่นคงสัดส่วนภาพเดิมให้อัตโนมัติ** (ระยะห่างระหว่างชิ้น
  ลายผูกกับขนาดชิ้นลายเป็นสัดส่วนในตัว engine อยู่แล้ว จึงไม่มีทางเกิดลาย
  เบียดกันหรือโล่งผิดปกติจากการปรับขนาด) — ลายเดิม seed เดิม องค์ประกอบ
  แบบเดิม แค่สเกลต่างกัน กดปุ่ม **100%** เพื่อกลับขนาดที่ gen มา และกด
  Generate ถ้าอยากเก็บขนาดใหม่เข้า Gallery
  > 🔒 ทุกลายที่สร้างออกมา **รับประกัน seamless โดยโครงสร้างของ engine เอง**
  > ไม่ใช่แค่ "ลองแล้วดูดี" — ระบบคำนวณขอบเขตจริงของทุกรูปทรง (จากพิกัด
  > ตรงๆ ไม่ใช่ประมาณด้วยมือ) ก่อนตัดสินใจว่าต้องวาดสำเนาที่ล้นขอบ tile
  > หรือไม่ จึงการันตีว่าไม่มีชิ้นลายไหนถูกตัดขาดที่ขอบโดยไม่มีคู่ต่อที่ฝั่ง

ปรับตามกติกาของเว็บนั้นๆ เป๊ะๆ พร้อมปุ่มคัดลอกทุกช่อง:

## 📌 คลังลายที่บันทึก — เก็บลายที่จะขาย + ติดตามสถานะส่งขาย

แผงใหม่ระหว่าง SEO กับ Gallery — ต่างจาก Gallery ตรงที่ **Gallery หมุนเวียน**
(ลายใหม่มาแทนที่เก่าเมื่อเกิน 24 ลาย) แต่**คลังนี้เก็บถาวร ไม่จำกัดจำนวนลาย** 🆕
(เก็บใน IndexedDB ของเบราว์เซอร์ซึ่งจุได้หลาย GB — ลายที่เคยบันทึกก่อน
เวอร์ชันนี้จะถูกย้ายเข้าที่เก็บใหม่ให้อัตโนมัติ):

1. กด **💾 บันทึกเข้าคลัง + ดาวน์โหลดชุดไฟล์** — ลายที่แสดงอยู่ (พร้อมทุก
   ค่าปรับ + seed) ถูกเก็บเข้าคลังทันที ตั้งชื่อให้อัตโนมัติจาก ชุดสี · หมวด ·
   layout **และระบบดาวน์โหลดชุดไฟล์ลงเครื่องให้อัตโนมัติเป็น zip เดียว** 🆕
   ข้างในมี 3 ไฟล์ครบพร้อมส่งขาย:
   - `ชื่อลาย.svg` — ภาพเดี่ยว ขนาดเต็ม 10000×10000 px
   - `ชื่อลาย-3x3.svg` — แบบต่อ 3×3 ขนาดเต็ม 10000×10000 px
   - `ชื่อลาย-SEO.txt` — ข้อความ SEO ของครบทั้ง 5 เว็บ เปิดอ่านคู่กันตอน
     กรอกฟอร์มอัปโหลดได้เลยไม่ต้องเปิดแอป
   (zip เก็บไฟล์แบบ byte-ต่อ-byte ไม่บีบอัดไม่ลดคุณภาพ — ได้ไฟล์เหมือน
   กด Export เองทุกประการ)
2. ในการ์ดของแต่ละลายมี **checkbox 5 เว็บ** (Shutterstock, Adobe Stock,
   Freepik, Creative Fabrica, Creative Market) — **ติ๊กเมื่อส่งขายเว็บนั้นแล้ว**
   ป้ายมุมขวาสรุปว่า "ส่งแล้ว x/5 เว็บ" (ครบ 5 เว็บป้ายเปลี่ยนเป็นสีเขียว)
3. มี**ช่องโน้ต**อิสระ เช่น วันที่ส่ง, ผลการรีวิว, ยอดขาย
4. กด **⬇️ ดาวน์โหลดชุดไฟล์** ในการ์ด — ดาวน์โหลด zip ชุดเดิมซ้ำได้ทุกเมื่อ
5. กด **โหลดกลับมาแก้/ดู SEO** (หรือคลิกรูป) — ลายกลับมาที่ preview พร้อม
   ค่าปรับครบ และแผง SEO ด้านบนแสดงข้อความของลายนั้นทันที ไว้คัดลอกไปวาง
   ตอนอัปโหลดขายทีละเว็บ
6. ปุ่ม **ลบ** เอาลายออกจากคลัง (มีถามยืนยันก่อน)

### 📦 ย้ายทั้งคลังลงเครื่อง + นำเข้า backup 🆕

- **📦 ย้ายทั้งคลังลงเครื่อง (ดาวน์โหลดแล้วล้างคลังอัตโนมัติ)** — กดปุ่มเดียว
  ได้ zip ใหญ่ไฟล์เดียวที่มี**โฟลเดอร์แยกของทุกลาย** (ภาพเดี่ยว + 3×3 ขนาด
  เต็ม + SEO ครบ 5 เว็บ) พร้อมไฟล์ `library-backup.json` ที่เก็บข้อมูลทุกอย่าง
  (ค่าปรับ, seed, โน้ต, สถานะติ๊กส่งขาย) — พอดาวน์โหลดแล้วระบบ**ล้างคลังใน
  แอปให้อัตโนมัติ** พื้นที่เก็บในเบราว์เซอร์จึงไม่มีวันเต็ม
- **📥 นำเข้า backup** — เลือกไฟล์ `library-backup.json` จาก zip ที่เคยย้าย
  ลงเครื่อง คลังทั้งหมดกลับมาครบทุกอย่าง (รวมโน้ตและสถานะส่งขาย) ใช้ย้าย
  คลังข้ามเครื่อง/ข้ามเบราว์เซอร์ได้ด้วย
- **📄 CSV Shutterstock / CSV Adobe Stock** 🆕 — ดาวน์โหลดไฟล์ metadata
  CSV ของทั้งคลัง (ทั้งสองเว็บรองรับการอัปโหลด CSV ผูก Title/Keywords/
  Category กับไฟล์เป็นชุด): อัปโหลดไฟล์ภาพ 20 ภาพ + CSV 1 ไฟล์ = metadata
  ครบทุกภาพ **ไม่ต้องกรอกฟอร์มทีละภาพอีกเลย** ชื่อไฟล์ใน CSV เป็น `.eps`
  ตรงกับไฟล์ที่แปลงจาก Affinity (ชื่อฐานเดียวกัน) — CSV สองไฟล์นี้แถมอยู่ใน
  zip ของ "ย้ายทั้งคลังลงเครื่อง" ด้วยอัตโนมัติ

> 💡 วงจรที่แนะนำ: บันทึกลายสะสมในคลัง → ทำงานส่งขาย/ติ๊กสถานะ → พอครบ
> ชุดใหญ่ กด "ย้ายทั้งคลังลงเครื่อง" เก็บเป็นไฟล์ถาวร → คลังว่างพร้อมเริ่ม
> ชุดใหม่ — ถ้าอยากดูของเก่า นำเข้า backup กลับมาได้เสมอ

> 💡 วิธีใช้จริง: gen ลายจนพอใจ → บันทึกเข้าคลัง → export SVG ไปแปลง/ส่งขาย
> → กลับมาติ๊กเว็บที่ส่งแล้ว → พอผ่านรีวิว/ขายได้ จดไว้ในช่องโน้ต —
> มีระบบติดตามครบไม่ต้องทำตาราง Excel แยก

## ✏️ เปิดไฟล์ต่อใน Affinity Designer 2 (iPad)

1. Export **single tile** จากแอป → ได้ไฟล์ `.svg`
2. ใน Affinity Designer 2 เลือก Open → เลือกไฟล์ svg
3. โครงสร้าง layer ที่ได้:
   - `layer-background` — สี่เหลี่ยมพื้นหลัง (เปลี่ยนสีได้ทันที)
   - `layer-pattern` → `motif-1`, `motif-2`, ... — แต่ละชิ้นลายแยก group
     ของใครของมัน แก้สี/ย้าย/ลบ/หมุนรายชิ้นได้
4. ทุก shape เป็น vector path แท้ ไม่มี filter/effect แปลกๆ — ไฟล์เปิดแล้ว
   สี ตำแหน่ง ขนาด artboard ตรงตาม preview ทุกประการ
5. ชิ้นที่ล้นขอบ tile จะถูก clip ด้วย `tile-clip` — ถ้าจะแก้ชิ้นขอบ
   อย่าลืมว่าสำเนาของมันโผล่ฝั่งตรงข้ามด้วย (นั่นคือหัวใจของ seamless)

> ⚠️ ถ้าแก้ตำแหน่ง motif ริมขอบใน Affinity ลายอาจไม่ seamless อีกต่อไป —
> แก้สี/รายละเอียดภายในชิ้นปลอดภัยกว่า หรือกลับมาแก้ที่แอปด้วย seed เดิม

## 📤 ส่งไฟล์ขายผ่าน Affinity Designer 2 (iPad) ให้ผ่านการตรวจ

ไฟล์จากแอปเป็น SVG ล้วนสะอาด (ไม่มี raster, ไม่มี filter, ไม่มี metadata ใดๆ)
แต่**เว็บ stock ใหญ่ไม่รับ SVG ตรงๆ** — ต้องใช้ Affinity แปลงเป็นฟอร์แมตที่
แต่ละเว็บต้องการ:

| เว็บ | ไฟล์เวคเตอร์ | JPEG preview | วิธีใน Affinity iPad |
|---|---|---|---|
| **Shutterstock** | **EPS** เท่านั้น | แนบคู่ได้ (ชื่อไฟล์เดียวกัน) | เปิด SVG → Export → EPS |
| **Adobe Stock** | **AI หรือ EPS** | ไม่ต้อง (เว็บ render เอง) | เปิด SVG → Export → EPS |
| **Freepik** | **EPS** | **ต้องแนบ JPG คู่เสมอ** | Export EPS + Export JPEG |
| **Creative Fabrica** | SVG ได้เลย (แนบ EPS/PNG เพิ่มยิ่งดี) | ใช้เป็นภาพปก | ใช้ไฟล์จากแอปตรงๆ ได้ |
| **Creative Market** | แพ็กอะไรก็ได้ใน zip | ใช้เป็นภาพปก | จัดชุดเอง |

**เคล็ดลับให้ผ่านง่ายขึ้น:**
1. **JPEG preview ต้องตรงกับไฟล์เวคเตอร์** — ถ้าไฟล์เวคเตอร์เป็น tile เดี่ยว
   ให้ทำ preview จากไฟล์เดี่ยว ถ้าอยากใช้ preview 3×3 ให้ export EPS จาก
   ไฟล์ 3×3 ด้วย (จับคู่เนื้อหาเหมือนกัน) — reviewer เช็คว่า preview
   ตรงกับเวคเตอร์จริง
2. Export JPEG ที่ **~5000×5000 px, คุณภาพ 90+, สี sRGB** ก็เกินเกณฑ์ขั้นต่ำ
   (4MP) แล้ว ไม่จำเป็นต้อง 10000px (ไฟล์ใหญ่อัปโหลดช้าโดยไม่ได้อะไรเพิ่ม)
3. หมวด **Line Art** (ลายเส้น stroke เยอะ): ก่อน export EPS ให้เลือกทุก layer
   แล้วใช้ **Layer → Expand Stroke** — Shutterstock ชอบเวคเตอร์ที่แปลงเส้น
   เป็น shape แล้ว (หมวดอื่นมี stroke ประปรายไม่ค่อยมีปัญหา แต่ทำก็ยิ่งชัวร์)
4. อย่าติ๊กช่อง "Created using generative AI" — ลายจากแอปนี้สร้างด้วย
   อัลกอริทึมเชิงกำหนด (procedural/deterministic) ไม่ใช่ generative AI
   และในไฟล์ไม่มี metadata ใดๆ ที่บ่งชี้ AI

| Palette | **18** | ชุดสีสำเร็จรูป (ไม่นับ custom color ที่เลือก hex เองได้อิสระ) |
| Colors (2-6) | **5** | จำนวนสีที่ใช้จากพาเลตต์ |
| Density (0-100% ทีละ 5%) | **21** | ตัวปรับความหนาแน่น |
| **รวม** | **≈ 130,791,780** | 4,943 × 14 × 18 × 5 × 21 |

ตัวเลขนี้**ยังไม่รวม** motif size (121 ระดับ), rotation randomness (181
ระดับ), scale jitter (61 ระดับ), mirror symmetry (2), radial symmetry fold

การหมุน/สุ่มรูปทรงของทุกชิ้นลายในการ generate ครั้งนั้น) — รวมค่าพวกนี้เข้าไป

**ขอบเขตล่างแบบระมัดระวัง (conservative lower bound)** ไม่ใช่ตัวเลขโฆษณาเกินจริง

  `library-backup.json` แล้ว**ล้างคลังอัตโนมัติ**กันพื้นที่เต็ม
- 📥 **นำเข้า backup**: กู้คลังทั้งหมด (รวมโน้ต + สถานะส่งขาย) กลับจากไฟล์
