Workflow

  1. เลือก Style Family / Pattern Type / Composition ที่ต้องการ
  2. กด "สร้าง Prompt" แล้วคัดลอก
  3. วางใน ChatGPT หรือ Claude แล้วรับ JSON กลับมา
  4. วางใน แท็บ AI JSON → ปรับ JSON อัตโนมัติ → นำ JSON เข้า Engine

คู่มือใช้งาน

1. เลือก Style Family และคลิกไอเดียที่ชอบ หรือกรอก Concept เอง
2. กด "สร้าง Prompt" แล้วนำไปถาม ChatGPT / Claude เพื่อให้ช่วยคิดคอนเซ็ปต์และ keyword
3. นำ JSON ที่ได้กลับมาใส่ในแท็บ AI JSON แล้วกด "นำ JSON เข้า Engine"
4. ตรวจ Preview 3×3 ให้แน่ใจว่า repeat เนียน ไม่มีรอยต่อ
5. Export SVG
6. เปิดไฟล์ SVG ใน Affinity Designer 2 (iPad) เพื่อปรับแต่งรายละเอียดก่อนส่งขาย
7. ดาวน์โหลด Metadata CSV เพื่อกรอก title/description/keywords ตอนอัปโหลดขึ้น stock site
