# Build 025 Before/After Summary — Luxury Floral Composition Engine

## What "before" and "after" mean in this build

`luxuryComposition` (the new Composition Profile / Hero Dominance /
Topology-Aware Placement / Connector Quality / Repair Engine V2 system,
Phases 2-8) ships **disabled by default** — see `BUILD_025_AUDIT.md`
Section 6. So unlike a normal before/after ("last build's committed code"
vs "this build's committed code"), here:

- **"before" = production**: `luxuryFloral`'s current, shipped code path
  (`luxuryComposition` unset). This is exactly what a user gets today and
  after this build ships.
- **"after" = experimental**: the same seed, same style, with
  `luxuryComposition: true` forced on in-memory. This code exists in the
  repository (fully tested) but is not reachable through the shipped UI or
  Style DNA preset.

This is disclosed evidence *for* the audit's disposition (why the flag
stays off), not a claim that "after" is what ships.

## Visual reading guide (what to look for in the 100 rendered pairs)

- **Fewer stray single-flower islands, more often**: the "after" renders do
  show visibly fewer isolated single-motif confetti-points scattered with no
  neighbor, consistent with the -6pp measured improvement — Hero Dominance
  Engine's bigger, more visually anchoring heroes and Connector Quality's
  scored (not coin-flip) bridges are doing real work.
- **But at the cost of more empty channels**: several "after" renders show
  a visibly larger empty gap between bouquet units than "before" — the
  measured +8.67pp `deadSpace` regression, traced in
  `BUILD_025_AUDIT.md` Section 7 to the topology-guaranteed secondary/
  satellite anchors pulling members closer to their own unit's primary than
  the original whole-tile scatter would otherwise leave them, at the cost of
  inter-unit spacing.
- **≤30% target still not visually achieved**: even in the improved "after"
  renders, a majority of tiles still show at least one clearly disconnected
  single motif — the 54.67% rate is a real reduction from 60.67%, not a
  qualitative fix.

## Honest disposition

This evidence supports `BUILD_025_AUDIT.md`'s finding: a real, measurable,
architecturally sound improvement that does not clear the brief's bar and
trades one defect (fragmentation) partially for another (dead space). The
flag stays off; see `BUILD_025_REPORT.md` for the full verdict.
